# Evaluate module-trait relationships in a WGCNA network

Evaluates associations between module eigengenes and experimental groups
using correlation analysis. The function uses module eigengenes obtained
during WGCNA network construction to identify modules associated with a
binary experimental condition.

Experimental groups are encoded as a binary trait, with the reference
group represented by 0 and the comparison group by 1. Pearson
correlation coefficients, corresponding p-values, and Benjamini-Hochberg
adjusted p-values are calculated for each module.

Results include a module-trait association table and correlation matrix.
An optional heatmap can be generated to visualize the direction and
magnitude of module-trait relationships.

## Usage

``` r
rna_wgcna_module_trait(
  project,
  group = NULL,
  reference = NULL,
  plot = TRUE,
  save = TRUE
)
```

## Arguments

- project:

  An `rna_project` object containing a previously constructed WGCNA
  network generated by
  [`rna_wgcna`](https://luiz-garcia-r.github.io/autornaR/reference/rna_wgcna.md).

- group:

  Optional character vector specifying the two experimental groups to
  compare. Both groups must be represented among the samples included in
  the original network. If `NULL`, groups are automatically identified
  when exactly two non-missing groups are available. Defaults to `NULL`.

- reference:

  Optional character string specifying the reference group. The
  reference group is encoded as 0, whereas the other selected group is
  encoded as 1. If `NULL`, the first selected group is used. Defaults to
  `NULL`.

- plot:

  Logical. If `TRUE`, generates a heatmap displaying module-trait
  correlation coefficients, with colors representing their direction and
  magnitude. Defaults to `TRUE`.

- save:

  Logical. If `TRUE`, attaches the analysis result to the project under
  `analyses$wgcna_module_trait` and invisibly returns the updated
  project. Otherwise, invisibly returns an object of class
  `wgcna_module_trait_result`. Defaults to `TRUE`.

## Value

If `save = TRUE`, invisibly returns the updated `rna_project` object
containing the module-trait analysis result.

If `save = FALSE`, invisibly returns an object of class
`wgcna_module_trait_result`, containing:

- `module_trait_results`: a data frame containing module identifiers,
  colors, selected groups, correlation coefficients, p-values, and
  FDR-adjusted p-values.

- `correlation`: a matrix of module-trait correlation coefficients.

- `pvalues`: a matrix of corresponding statistical p-values.

- `parameters`: a list containing selected groups, correlation settings,
  and sample counts.

- `timestamp`: date and time of analysis.

## Input requirements

The function requires a previously constructed WGCNA network containing
module eigengenes. Sample metadata must contain the columns `Sample` and
`Group`, with unique sample identifiers matching the row names of the
module eigengene matrix.

Metadata are automatically aligned to the eigengene matrix, and samples
outside the selected groups are excluded. Samples with missing group
assignments or incomplete eigengene values are also excluded.

Both selected groups must contain at least one complete observation,
with at least three complete samples available overall.

## Analysis

Module-trait relationships are evaluated using Pearson correlations
between each module eigengene and the binary experimental trait. For
binary traits, this is mathematically equivalent to a point-biserial
correlation.

Positive correlations indicate higher eigengene values in the comparison
group, whereas negative correlations indicate higher values in the
reference group.

Statistical significance is estimated using the Student approximation
implemented in
[`corPvalueStudent`](https://rdrr.io/pkg/WGCNA/man/corPvalueStudent.html).
P-values are adjusted across modules using the Benjamini-Hochberg
procedure to control the false discovery rate (FDR).

Results are ranked by adjusted p-values, and the selected contrast is
recorded in the resulting object.

## Interpretation

Correlation magnitude reflects the strength of the association between
module eigengenes and the experimental condition. Statistical
significance should be interpreted together with correlation magnitude,
sample size, and adjusted p-values.

Module-trait associations identify modules whose expression patterns are
associated with the selected condition, but do not establish causal
relationships or demonstrate direct regulation of module genes.

## Scope and limitations

The function evaluates one binary contrast at a time and does not adjust
for additional covariates, confounding factors, repeated measurements,
or other sources of sample dependence.

The analysis uses module eigengenes calculated during network
construction and does not identify differential co-expression or changes
in network topology between experimental groups. Designs involving
relevant covariates or complex sampling structures may require
complementary regression or mixed-effects models.
