# Gene Set Enrichment Analysis (GSEA) from RNA-seq data

Performs Gene Set Enrichment Analysis (GSEA) using ranked gene lists
derived from differential expression results generated by
[`rna_compare()`](https://luiz-garcia-r.github.io/autornaR/reference/rna_compare.md).

Gene ranking can be based on moderated t-statistics or log2 fold-change.
The function integrates MSigDB gene sets via msigdbr and performs
enrichment using fgsea, supporting multiple organisms and gene ID types.

Annotation is performed automatically using organism-specific
org.\*.eg.db databases.

## Usage

``` r
rna_gsea(
  project,
  top_n = 10,
  geneset_collection = "C5",
  geneset_subcollection = "GO:BP",
  ranking_method = c("stat", "log2fc"),
  padj_gsea = 0.05,
  heatmap_mode = c("adaptive", "NES_ordered", "split_direction"),
  plot_heatmap = TRUE,
  enrich_plot = FALSE,
  seed = NULL,
  save = TRUE
)
```

## Arguments

- project:

  `rna_project` object created by
  [`rna_project()`](https://luiz-garcia-r.github.io/autornaR/reference/rna_project.md).

- top_n:

  Integer. Number of top enriched pathways to retain (default: `10`).

- geneset_collection:

  Character. MSigDB collection (e.g., `"C2"`, `"C5"`).

- geneset_subcollection:

  Character. Subcollection within MSigDB (e.g., `"GO:BP"`,
  `"CP:REACTOME"`).

- ranking_method:

  Character. Method used for gene ranking: `"stat"` (t-statistic) or
  `"log2fc"`.

- padj_gsea:

  Numeric. Adjusted p-value cutoff for filtering enriched pathways
  (default: `0.05`).

- heatmap_mode:

  Character. Strategy for selecting pathways in the heatmap:
  `"adaptive"` (balanced), but keeping biological effect `"NES_ordered"`
  (order by NES) or `"split_direction"` (balanced up/down).

- plot_heatmap:

  Logical. Whether to display a NES heatmap of enriched pathways.

- enrich_plot:

  Logical. Whether to generate enrichment plots for top pathways.

- seed:

  Optional integer used to set the random seed for reproducibility. If
  `NULL`, the existing random number generator state is used.

- save:

  Logical. Whether to store results in the active `rna_project`.

## Value

An object of class `gsea_result` containing:

- ranking:

  Named numeric vector of ranked genes.

- pathways:

  List of gene sets used in the analysis.

- gsea_full:

  Full GSEA result table.

- gsea_top:

  Filtered table of top enriched pathways.

- enrich_plots:

  List of enrichment plots (if requested).

- contrast:

  Comparison used for ranking.

- params:

  List of analysis parameters.

## Details

This function operates on results generated by
[`rna_compare()`](https://luiz-garcia-r.github.io/autornaR/reference/rna_compare.md),
ensuring consistency between differential expression and enrichment
analysis.

The selected comparison defines the gene ranking used in GSEA.

For zebrafish, GO collections (C5) are not available in MSigDB and are
automatically replaced with Reactome pathways (C2:CP:REACTOME).

## Common gene set configurations

The MSigDB database is organized into collections (e.g., "C2", "C5"),
which may not be intuitive. Below are biologically meaningful
configurations for common analysis goals:

**General biology (Hallmark pathways)**

- Concise, non-redundant representation of major biological processes

- Recommended as a starting point

- `geneset_collection = "H"`

**Classical pathways (Reactome, KEGG, BioCarta)**

- Detailed signaling and metabolic pathways

- More granular but also more redundant

- `geneset_collection = "C2"`

- `geneset_subcollection = "CP"`

**Reactome pathways (highly curated)**

- Structured, hierarchical pathway knowledgebase

- Good balance between detail and interpretability

- `geneset_collection = "C2"`

- `geneset_subcollection = "CP:REACTOME"`

**Gene Ontology (GO)**

- Broad functional annotation (can be redundant)

- `geneset_collection = "C5"`

- Subcollections:

  - `"GO:BP"` – biological processes

  - `"GO:MF"` – molecular functions

  - `"GO:CC"` – cellular components

**Cell type signatures**

- Gene sets representing specific cell populations

- Useful for inferring cellular composition or activation

- `geneset_collection = "C8"`

**Immunologic signatures (C7)**

- Immunologic gene sets (stimuli, cell states, perturbations)

- Particularly useful in infection, vaccination, and inflammation
  studies

- `geneset_collection = "C7"`

**Oncogenic signatures**

- Gene sets derived from oncogenic pathway perturbations

- Useful for cancer-related analyses

- `geneset_collection = "C6"`

**Tip: Choosing a collection:**

- Use Hallmark ("H") for a clean global signal

- Use C2/Reactome for pathway-level interpretation

- Use GO (C5) for hypothesis generation

- Use C7/C8 when biological context (immune/cell types) is central

**Interpretation:** Positive normalized enrichment scores (NES) indicate
pathways enriched in the test condition, while negative NES values
indicate enrichment in the reference condition.

## Gene ranking

- `stat`: prioritizes genes with strong effect size and low variance.

- `log2fc`: emphasizes magnitude of change.

## Visualization

- Enrichment plots show running enrichment score for individual
  pathways.

- Heatmaps summarize normalized enrichment scores (NES).

## Pipeline context

This function is typically used after
[`rna_normalize()`](https://luiz-garcia-r.github.io/autornaR/reference/rna_normalize.md)
and before downstream analyses such as
[`rna_compare()`](https://luiz-garcia-r.github.io/autornaR/reference/rna_compare.md),
or clustering.
