# Calculate WGCNA Network Metrics

Calculates gene-level and module-level connectivity metrics from an
existing WGCNA network. Metrics include module membership (kME),
intramodular connectivity (kWithin), and connectivity to genes outside
the assigned module (kOut and kTotal).

## Usage

``` r
rna_wgcna_metrics(project, group = NULL, save = TRUE)
```

## Arguments

- project:

  An `rna_project` object containing a previously constructed WGCNA
  network result, generated by
  [`rna_wgcna`](https://luiz-garcia-r.github.io/autornaR/reference/rna_wgcna.md).

- group:

  Character vector specifying one or more metadata groups for
  group-specific metric evaluation. If `NULL`, only global network
  metrics are calculated. If one or more groups are supplied, global
  metrics are calculated alongside the corresponding group-specific
  evaluations. Each selected group must contain at least three samples.
  Defaults to `NULL`.

- save:

  Logical. If `TRUE`, attaches the metrics result to the project under
  the `analyses` slot with subtype `"wgcna_metrics"` and invisibly
  returns the updated project. If `FALSE`, does not attach the result
  and instead invisibly returns an object of class
  `wgcna_metrics_result`. Defaults to `TRUE`.

## Value

If `save = TRUE`, invisibly returns the updated `rna_project` object.

If `save = FALSE`, invisibly returns an object of class
`wgcna_metrics_result`, containing:

- gene_metrics:

  Data frame containing gene-level metrics for the global network,
  including gene identifiers, module assignments, kME, kWithin, kOut,
  and kTotal.

- module_summary:

  Data frame containing module-level summaries for the global network.

- by_group:

  Named list containing gene-level metrics, module-level summaries, and
  sample counts for each selected group. Empty when no group-specific
  evaluation is requested.

- parameters:

  List containing the correlation method, soft-thresholding power,
  network type, and selected groups used in the evaluation.

- timestamp:

  Date and time at which the metrics were calculated.

## Details

The function calculates metrics for the global network and can
optionally perform additional group-specific evaluations using the same
globally defined modules. Group-specific evaluations recalculate
connectivity and module membership within each selected group without
reconstructing the network or redefining module assignments.

The following metrics are calculated for each gene:

- kME (module membership):

  Pearson correlation between gene expression and the eigengene of its
  assigned module. The correlation method used during network
  construction is retained for consistency.

- kWithin (intramodular connectivity):

  Sum of adjacency values between a gene and the other genes belonging
  to the same module.

- kOut (extramodular connectivity):

  Sum of adjacency values between a gene and genes belonging to other
  modules.

- kTotal (total connectivity):

  Sum of intramodular and extramodular connectivity (`kWithin + kOut`).

Module-level summaries include the number of genes assigned to each
module and the mean and median values of kME and kWithin. Unassigned
genes (grey module) are excluded from module-level summaries. Their kME
values are returned as `NA`, since they do not belong to a defined
module eigengene.

When group-specific evaluation is requested, the original global module
assignments and eigengenes are retained as the reference. Gene
expression and adjacency values are evaluated using only samples
belonging to each selected group. Consequently, kME represents the
correlation with the corresponding global module eigengene evaluated
within the selected group, while connectivity metrics are recalculated
using the group's expression data.

Group-specific metrics describe connectivity patterns within each group
and should not be interpreted as formal statistical tests of differences
between networks. Differences in connectivity may also reflect
differences in sample size and expression variability.
