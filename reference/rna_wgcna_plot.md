# Visualize WGCNA Module Networks

Generates network visualizations from an existing WGCNA network,
allowing the inspection of relationships between modules or the
intramodular connectivity structure of an individual module.

Two visualization modes are available. The module network view
represents relationships between module eigengenes using pairwise
correlations, whereas the module detail view represents gene-level
adjacency relationships within a selected module, highlighting highly
connected hub genes.

The function uses the original WGCNA network and module assignments. It
does not reconstruct the network, redefine modules, or recalculate
module detection.

## Usage

``` r
rna_wgcna_plot(
  project,
  view = c("module_network", "module_detail"),
  module = NULL,
  group = NULL,
  edge_threshold = NULL,
  hub_quantile = 0.9,
  layout = c("fr", "kk", "circle", "dh", "stress"),
  labels = TRUE,
  remove_isolated = FALSE,
  seed = NULL,
  plot = TRUE,
  save = FALSE
)
```

## Arguments

- project:

  An `rna_project` object containing a previously constructed WGCNA
  network result, generated by
  [`rna_wgcna`](https://luiz-garcia-r.github.io/autornaR/reference/rna_wgcna.md).

- view:

  Character string specifying the visualization type. Available options
  are:

  `"module_network"`

  :   Generates a network in which nodes represent modules and edges
      represent correlations between module eigengenes.

  `"module_detail"`

  :   Generates a gene-level network representing adjacency
      relationships within a selected module, with hub genes
      highlighted.

  Defaults to `"module_network"`.

- module:

  Character string specifying the module to visualize when
  `view = "module_detail"`. Must match an existing module identifier in
  the WGCNA network. Unassigned genes (grey module) cannot be selected.
  Defaults to `NULL`.

- group:

  Character string specifying the metadata group used for group-specific
  visualization. If `NULL`, the global network data are used. When a
  group is specified, the corresponding expression data and module
  eigengenes are used for the selected visualization, while the original
  global module assignments are retained. Defaults to `NULL`.

- edge_threshold:

  Numeric value specifying the minimum edge strength required for an
  edge to be included in the visualization. Its interpretation depends
  on the selected view:

  `"module_network"`

  :   Minimum absolute Pearson correlation between module eigengenes.
      Values range from greater than 0 to 1. Defaults to `0.30`.

  `"module_detail"`

  :   Minimum gene-to-gene adjacency value within the selected module.
      Values range from greater than 0 to 1. Defaults to `0.10`.

- hub_quantile:

  Numeric value between 0 and 1 specifying the quantile used to identify
  hub genes in the `"module_detail"` view. Genes with intramodular
  connectivity (`kWithin`) at or above the corresponding quantile are
  classified as hub genes. Defaults to `0.90`.

- layout:

  Character string specifying the graph layout algorithm used by
  `ggraph`. Common options include `"fr"` (Fruchterman-Reingold), `"kk"`
  (Kamada-Kawai), `"circle"`, `"dh"`, and `"stress"`. Defaults to
  `"fr"`.

- labels:

  Logical. If `TRUE`, displays module identifiers in the
  `"module_network"` view and hub gene labels in the `"module_detail"`
  view. If `FALSE`, suppresses all node labels in both visualization
  modes. Defaults to `TRUE`.

- remove_isolated:

  Logical. If `TRUE`, removes nodes without connections from the
  generated network visualization. If `FALSE`, all nodes are retained,
  including isolated nodes. This argument applies to the
  `"module_network"` view. Defaults to `FALSE`.

- seed:

  Optional integer used for reproducibility.

- plot:

  Logical. If `TRUE`, prints the generated visualization. If `FALSE`,
  returns the visualization object without displaying the plot. Defaults
  to `TRUE`.

- save:

  Logical. If `TRUE`, attaches the visualization result to the project
  under the `analyses` slot with subtype `"wgcna_plot"` and invisibly
  returns the updated project. If `FALSE`, does not attach the result
  and instead invisibly returns an object of class `wgcna_plot_result`.
  Defaults to `FALSE`.

## Value

If `save = TRUE`, invisibly returns the updated `rna_project` object.

If `save = FALSE`, invisibly returns an object of class
`wgcna_plot_result`, containing:

- plot:

  The generated `ggraph`/`ggplot` visualization. May be `NULL` when
  `plot = FALSE`.

- graph:

  An `igraph` object containing the network structure and associated
  node and edge attributes.

- nodes:

  Data frame containing node-level information, including module
  assignments, module colors, gene identifiers, connectivity
  information, and visualization attributes. The exact columns depend on
  the selected view.

- edges:

  Data frame containing the network edges and their associated
  correlation or adjacency attributes, depending on the selected view.

- correlation:

  Matrix of pairwise module eigengene correlations for the
  `"module_network"` view. Returns `NULL` for the `"module_detail"`
  view.

- parameters:

  List containing the selected visualization parameters, group
  information, sample count, network dimensions, edge threshold, layout,
  and hub identification settings when applicable.

- timestamp:

  Date and time at which the visualization object was generated.

## Details

The module network view summarizes relationships between modules using
Pearson correlations between their eigengenes. Each node represents a
module, with node size proportional to the number of assigned genes.
Edges represent pairwise eigengene correlations exceeding the selected
absolute correlation threshold. Positive and negative correlations are
visually distinguished.

The module detail view reconstructs the adjacency relationships between
genes belonging to the selected module using the expression data
available for the selected group. Gene connectivity is quantified using
intramodular connectivity (`kWithin`), calculated as the sum of
adjacency values connecting each gene to the other genes in the same
module. Edges are retained according to the selected adjacency
threshold.

Hub genes are identified from the distribution of intramodular
connectivity values. The selected `hub_quantile` defines the minimum
connectivity quantile used for hub classification. Hub genes are
highlighted in the visualization and labeled using available gene
symbols. When a gene symbol is unavailable, the corresponding gene
identifier is used instead. Duplicated gene symbols are disambiguated
using their original gene identifiers.

When group-specific visualization is requested, the original global
module assignments are retained. However, eigengene correlations and
gene-level adjacency relationships are evaluated using the expression
data from the selected group. Consequently, differences between
group-specific visualizations may reflect changes in expression
relationships and connectivity patterns, as well as differences in
sample size and expression variability.

These visualizations are intended for exploratory network inspection and
biological interpretation. Correlations and adjacency values represent
network relationships and should not be interpreted as evidence of
direct molecular interactions, causal relationships, or statistically
significant differences between groups.

The selected graph layout determines the spatial arrangement of nodes
and does not represent biological distance or interaction strength
independently of the network edges.
