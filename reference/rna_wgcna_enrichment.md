# Characterize WGCNA modules through functional enrichment analysis

Performs gene set enrichment analysis (GSEA) to characterize the
biological processes and molecular functions associated with WGCNA
co-expression modules.

Genes are ranked according to their signed module membership (kME),
calculated as the correlation between gene expression and the
corresponding module eigengene. Enrichment analysis is performed
independently for each selected module using the
[`fgseaMultilevel`](https://rdrr.io/pkg/fgsea/man/fgseaMultilevel.html)
algorithm.

Gene sets can be retrieved automatically from MSigDB or supplied by the
user as a named list or GMT file. Gene identifiers are mapped to the
identifiers used in the original WGCNA network before enrichment
analysis.

## Usage

``` r
rna_wgcna_enrichment(
  project,
  modules = NULL,
  geneset_collection = "C5",
  geneset_subcollection = "GO:BP",
  pathways = NULL,
  pathway_id_type = "symbol",
  min_size = 10,
  max_size = 500,
  plot_top = 5,
  plot = TRUE,
  plot_dir = NULL,
  save = TRUE
)
```

## Arguments

- project:

  An `rna_project` object containing a previously constructed WGCNA
  network generated by
  [`rna_wgcna`](https://luiz-garcia-r.github.io/autornaR/reference/rna_wgcna.md)
  and the corresponding gene annotation.

- modules:

  Optional character vector specifying the WGCNA module colors to
  analyze. If `NULL`, all assigned modules are analyzed. Unassigned
  genes (grey modules) are excluded. Defaults to `NULL`.

- geneset_collection:

  Character string specifying the MSigDB collection to retrieve when
  `pathways = NULL`. Common options include `"H"` (Hallmark), `"C2"`
  (curated gene sets), `"C5"` (ontology gene sets), `"C6"` (oncogenic
  signatures), `"C7"` (immunologic signatures), and `"C8"` (cellular
  signatures). Defaults to `"C5"`.

- geneset_subcollection:

  Optional character string specifying the MSigDB subcollection. For
  example, `"GO:BP"` selects Gene Ontology Biological Process gene sets,
  while `"CP:REACTOME"` selects Reactome pathways. Some collections do
  not support subcollections. Defaults to `"GO:BP"`.

- pathways:

  Optional collection of custom gene sets, supplied either as a named
  list of gene identifiers or as a path to a GMT file. If `NULL`, gene
  sets are retrieved automatically from MSigDB according to
  `geneset_collection` and `geneset_subcollection`. Defaults to `NULL`.

- pathway_id_type:

  Character string specifying the identifier type used in custom gene
  sets. Supported options are `"gene_id"`, `"symbol"`, and `"entrez"`.
  This argument is ignored when MSigDB gene sets are retrieved
  automatically, as MSigDB gene symbols are used. Defaults to
  `"symbol"`.

- min_size:

  Integer specifying the minimum number of mapped genes required for a
  gene set to be included in the enrichment analysis. Defaults to `10`.

- max_size:

  Integer specifying the maximum number of mapped genes allowed for a
  gene set to be included in the enrichment analysis. Defaults to `500`.

- plot_top:

  Integer specifying the maximum number of enriched pathways to
  visualize for each module. Pathways are selected according to their
  module-specific adjusted p-values (`padj_module`), regardless of
  statistical significance. Defaults to `5`.

- plot:

  Logical. If `TRUE`, generates enrichment plots for the top pathways of
  each analyzed module using
  [`plotEnrichment`](https://rdrr.io/pkg/fgsea/man/plotEnrichment.html).
  Defaults to `TRUE`.

- plot_dir:

  Optional character string specifying the directory in which enrichment
  plots are saved as PDF files. The directory is created recursively if
  it does not exist. If `NULL`, plots are not saved to disk. Defaults to
  `NULL`.

- save:

  Logical. If `TRUE`, attaches the analysis result to the project under
  `analyses$wgcna_enrichment` and invisibly returns the updated project.
  Otherwise, invisibly returns an object of class
  `wgcna_enrichment_result`. Defaults to `TRUE`.

## Value

If `save = TRUE`, invisibly returns the updated `rna_project` object.

If `save = FALSE`, invisibly returns an object of class
`wgcna_enrichment_result`, containing:

- `enrichment`: combined GSEA results for all analyzed module-by-pathway
  combinations, including enrichment scores, normalized enrichment
  scores, p-values, and adjusted p-values.

      \item \code{kME}: matrix of gene-module membership correlations between
      all network genes and module eigengenes.

      \item \code{rankings}: named list containing the signed kME rankings used
      for each analyzed module.

      \item \code{gene_sets}: gene sets mapped to the identifiers used in the
      original WGCNA network and retained after size filtering.

      \item \code{pathway_mapping}: summary of original and mapped gene set
      sizes, including pathway inclusion status.

      \item \code{module_summary}: summary of the number of genes, tested
      pathways, and significant enrichment results for each module.

      \item \code{plots}: nested list containing the enrichment plots generated
      for each module.

      \item \code{parameters}: organism, gene set source, collection,
      identifier type, module selection, filtering thresholds, correlation
      method, and plotting configuration.

      \item \code{data_summary}: summary of the number of genes, samples,
      modules, gene sets, and enrichment tests.

      \item \code{timestamp}: date and time of analysis.

## Input requirements

The project must contain a valid WGCNA result generated by
[`rna_wgcna`](https://luiz-garcia-r.github.io/autornaR/reference/rna_wgcna.md).
The original result must include:

- An expression matrix with samples in rows and genes in columns.

- A gene-module assignment table containing gene identifiers, module
  labels, and module colors.

- Module eigengenes corresponding to the original expression matrix.

When custom gene sets or MSigDB gene sets use symbols or Entrez
identifiers, gene annotation must contain the corresponding identifiers
and their mapping to the gene identifiers used in the WGCNA network.

Gene sets are mapped to the original network identifiers before
analysis. Only mapped genes belonging to the original WGCNA network are
retained. Gene sets are subsequently filtered according to their mapped
sizes.

## Analysis

Enrichment analysis is performed independently for each selected module
using the signed module membership (kME) as the ranking statistic.

kME is calculated as the correlation between each gene and the
corresponding module eigengene, using the correlation method specified
during the original WGCNA analysis.

For each module, genes are ranked in decreasing order of kME. The
resulting rankings are analyzed using the multilevel GSEA algorithm
implemented in
[`fgseaMultilevel`](https://rdrr.io/pkg/fgsea/man/fgseaMultilevel.html).

Two levels of multiple-testing correction are reported:

- **Module-specific FDR (`padj_module`):** Benjamini-Hochberg adjusted
  p-values calculated independently within each module, considering all
  tested gene sets.

      \item \strong{Global FDR (\code{padj_global}):}
      Benjamini-Hochberg adjusted p-values calculated across all
      module-by-pathway enrichment tests combined.

Enrichment plots display the running enrichment score of selected gene
sets along the ranked gene list. The top pathways are selected according
to module-specific adjusted p-values, even when they do not reach the
conventional significance threshold.

## Interpretation

Enrichment results characterize the functional composition of WGCNA
modules and identify biological processes whose genes are concentrated
toward one end of the module membership ranking.

The normalized enrichment score (NES) reflects the direction and
magnitude of gene set enrichment relative to the signed kME ranking. Its
sign indicates the direction of enrichment along that ranking, which
depends on the orientation of the corresponding module eigengene.

Importantly, positive or negative NES values do not directly indicate
biological pathway activation or inhibition. They describe the relative
position of gene set members within the kME ranking and should be
interpreted in the context of module eigengene orientation and gene
expression patterns.

Enrichment results describe functional associations within co-expression
modules and do not establish causal relationships, biochemical pathway
activity, or functional activation of individual genes or cellular
processes.

The analysis is based on the original WGCNA network and does not perform
differential expression analysis, module-trait association testing,
differential enrichment between experimental groups, or independent
network reconstruction.

Statistical significance should be interpreted considering both
module-specific and global FDR values, gene set size, annotation
coverage, and the biological context of the analyzed modules.
